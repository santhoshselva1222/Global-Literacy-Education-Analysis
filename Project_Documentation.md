# Global Literacy & Education Trends: An Analytical Study

## Project Overview
This project analyzes global literacy and education trends across countries and years using Python, Excel, and Power BI.

## Objectives
- Analyze global adult literacy rates.
- Study average years of schooling.
- Compare GDP per capita with education indicators.
- Examine youth literacy gender gaps.
- Visualize trends through an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- Excel
- Power BI
- GitHub

## Project Files
- `Global_Literacy_Education_Trends.ipynb` – Python analysis notebook
- `global_education_featured.xlsx` – Cleaned dataset
- `Global_Literacy_Education_Analysis.pbix` – Power BI dashboard

## Key Findings
The analysis explores relationships between literacy, schooling, GDP per capita, and youth literacy gender gaps. Correlation results indicate associations, not causation.
